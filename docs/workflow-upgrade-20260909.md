## Product contract

One program, many views. The canonical program is the existing `mx_ops.geo_programs` entity, not a Home copy plus a Globe copy. Home and the suite Geology Globe create/edit the same UUID/version. Processing campaigns retain their existing UUIDs and become compatibility projections of the same program. Old geological source data, sampling rules, boundary imports, GIC, corporate/clothing and the public plant route remain in place.

Navigation: Home / Programs / Geology / Plant / Gold / Work / Reports. Relevant module links select a permitted project/facility when the current scope is incompatible. Home creates work programs and tasks, surfaces due/unassigned/blocked work and active programs, and retains operational totals behind details. The suite Globe has a program selector and typed Create program menu. Program detail links its work sequence, actual holes/metres/samples, people/equipment, original evidence, cost basis and audit history. Existing `/mineralx` remains an explicitly labelled browser-local legacy/source workspace; it does not silently become a shared system or copy records into the suite. Its banner opens the suite Globe; existing controlled migration remains available.

Tasks support general project work, packages, milestones, maintenance, handovers and issues. One responsible planning person, contributors, planned dates, priority, evidence and explicit prerequisites. List, board and fourteen-day calendar schedule are views of the same records. Cross-workspace prerequisites require current access to both scopes in the same organisation; unavailable predecessor detail is masked. Completed prerequisites cannot be silently reopened beneath active dependent work. Packages cannot hide unverified maintenance. Program close-out checks unfinished work. Planning personnel are not login accounts and grant no access; existing active accounts can be linked for My work.

Plant reuses the existing engineering-oriented P5 dashboard in a read-only reference context. Internal engineering revisions do not fetch or write the public review-note endpoint. Proposed/approved/commissioned configuration remains distinct. Actual equipment, service dates, maintenance requests and critical spares connect to the work register. Independent maintenance verification requires a different named supervisor with MFA. Original evidence and revisions are retained, not overwritten with a new drawing.

Energy contains installed assets, opening tank observations, deliveries, issues, transfers and independent dips. Chronological stock must remain non-negative and within tank capacity. A dip is a comparison, not an unexplained balancing adjustment. Meter observations distinguish generator/solar/grid/load/running hours/battery state; interval overlap and physical elapsed-time checks prevent double counting. Proposed capacity is not measured generation. Period filters exclude partially overlapping intervals rather than prorating. No total-site denominator, fuel-consumption inference or savings estimate is fabricated. kWh/t and L/t remain unestablished without a reviewed matching accounting boundary/denominator. No live meter, scale or inverter integration is claimed.

Gold has a dedicated entry page and each lot has a next useful action. Physical output, measurement/assay review, recognition and custody remain independent states. Evidence controls remain unchanged: no exact purity from a qualified result, no self-approval, no fake custody acknowledgement, no double-counted transformation, no recognition before the facility policy is established. Advanced actions remain available behind details. This is a guided work surface, not a forced wizard that invents missing measurements.
